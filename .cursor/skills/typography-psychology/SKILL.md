# Typography psychology

Source: Cyril Burt, *A Psychological Study of Typography* (Cambridge, 1959). Legibility, age, fatigue, serif vs sans in running text. Old data, still a reminder that type is a reading task, not a logo moodboard.

## Steal

Keep as a word must be read in a glance. Serif light on glass worked because it is language. A geometric logotype on the pill becomes a third trademark fighting Apple’s glass.

Do not set long UI sentences in display serif. Extra field is text. Overlay is two lines.

## Keep checks

* Glass cycle: `.serif` light 72. Not “Completed”. Not a plus.
* Extra prompt matches Today’s Keep. Same voice.

## Post shape

Burt measured whether type could be read when people were tired.

Keep on glass is a word you already know.

If you have to decode a mark, the day has already lost.

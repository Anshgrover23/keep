# User centered system design

Source: Norman and Draper, eds., *User Centered System Design* (1986). Essays including Norman cognitive engineering, Hutchins Hollan Norman on direct manipulation, Brenda Laurel interface as mimesis, Buxton on hands.

## Direct manipulation (that essay)

The object of interest is visible. Actions are incremental and reversible. The effect is immediately visible. Keep’s object is the day. Typing Keep is an incremental mark on that object.

## Interface as mimesis (Laurel)

Not decoration. A world the user can act in. Wallpaper is a world. Extra is a prop in that world. A feature matrix is a program booklet, not a play.

## Keep checks

* Do not mime a weather app. Mime standing under a sky.
* Smash K in the film is mimesis of gathering the day into one mark. Then stop.

## Post shape

In 1986 they argued for direct manipulation of objects, not command piles.

The object I can manipulate is today.

Keep is a line on that object. Liquid Glass is how the object shows light.

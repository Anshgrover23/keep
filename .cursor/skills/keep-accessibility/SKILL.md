# Keep accessibility

Accessibility is part of the product, not a polish pass.

## Surfaces

| Surface | Expectation |
| --- | --- |
| Wallpaper overlay | Visual atmosphere first. Do not steal desktop icon AX. |
| Menu extra | Labels name the job. Glance is readable. Today’s Keep is a field. |
| Settings | Keyboard reaches every control a pointer can. Grants are invitational. |
| Onboarding | Intention field is reachable. Optional calendar and location are not focus traps. |

Return and closing the extra both commit today’s Keep. Wallpaper is not a key window.

## Reduce Motion

Do not add extra scene thrash to prove the wallpaper is alive. Pause and hide still follow `WallpaperDisplayLinkPolicy`.

## VoiceOver

Labels match on-screen job names. No HTTP codes. Calendar off uses invitation copy. Approximate weather does not imply a GPS lock.
